## 二、技术架构（三层架构）

系统采用经典三层架构，全部代码自主编写：

```
┌─────────────────────────────────────────────────────────┐
│            前端展示层（HTML5 + CSS3 + JS + ECharts）         │
│  登录页 / 可视化大屏 / 筛选列表 / 岗位详情 / 后台管理         │
└───────────────────────────┬─────────────────────────────┘
                            │ HTTP / JSON
┌───────────────────────────┴─────────────────────────────┐
│        业务逻辑层（Python + Flask，五大核心模块）            │
│  数据管理 / 智能筛选引擎 / 可视化统计 / 输出生成 / 用户权限    │
└───────────────────────────┬─────────────────────────────┘
                            │ SQL
┌───────────────────────────┴─────────────────────────────┐
│        数据持久层（SQLite 单机 / MySQL 云端，5 张核心表）     │
│   user / job / label / archive / operation_log           │
└─────────────────────────────────────────────────────────┘
```

## 五、五大核心模块实现说明

### 模块一：数据管理模块（[services/data_service.py](file:///d:/jobselect/services/data_service.py)）

**自研核心算法：**

1. **薪资清洗算法** `parse_salary(text)`：正则识别区间（`5000-7000`/`5k-7k`/`5000~7000`）、单值、面议，统一输出 (min, max, text)。
2. **学历标准化** `parse_education(text)`：将"大专及以上""不限"等杂乱文本映射为 0-7 标准等级。
3. **福利标签拆分** `parse_welfare(text)`：先按 20 项标准化关键词字典匹配，再按分隔符切分补充。
4. **爱心岗位识别** `detect_caring(text)`：基于"爱心/帮扶/大龄/残疾/困难/脱贫"等关键词自动标记。
5. **持证优先识别** `detect_cert_priority(text)`：识别焊工证、叉车证、健康证等。

**子功能：** Excel 导入解析、岗位增删改查、按月归档（JSON 快照）、备份恢复。

### 模块二：智能复合筛选引擎（[services/filter_service.py](file:///d:/jobselect/services/filter_service.py)）

**自研核心逻辑：** `_build_where(filters)` 动态组装 AND 联合查询 SQL，支持 9 个维度叠加：
- 地区、爱心岗位、学历（等级 <= 判断可胜任）、薪资区间（max_salary >= 期望）、关键词、行业、班次、持证优先、福利标签（EXISTS 子查询）。
- 筛选后实时聚合 `aggregate_stats()` 同时回传统计数据，驱动图表联动刷新。
- 性能：分页查询 `LIMIT ? OFFSET ?`，千级数据响应 < 1 秒。

### 模块三：可视化统计模块（[services/viz_service.py](file:///d:/jobselect/services/viz_service.py)）

**自研核心逻辑：** 基于 ECharts 自主封装 option 模板生成函数：
- **指标卡片**：总数 / 爱心岗 / 8000+ 高薪岗 / 包食宿岗（SQL COUNT 聚合）
- **柱状图**：各行业岗位数量对比（GROUP BY industry）
- **饼图**：学历分布占比、薪资区间占比（CASE WHEN 区间归类）
- **联动机制**：任意筛选条件变更 → `refresh()` 重新请求 `/api/stats` → 全图表 setOption 重绘

### 模块四：输出与详情生成模块（[services/output_service.py](file:///d:/jobselect/services/output_service.py)）

**自研核心逻辑：**
1. `export_jobs_excel()`：openpyxl 渲染标准化劳务对接报表（标题行/表头/数据/爱心岗黄底/备注）。
2. `export_contacts_excel()`：批量导出企业联系人，用于线下招工通知。
3. `generate_detail_page(job_id)`：自研 HTML 模板渲染单岗位独立静态详情页，输出到 `data/detail_pages/`，适配手机转发与打印。

### 模块五：用户权限管理模块（[services/auth_service.py](file:///d:/jobselect/services/auth_service.py)）

**自研核心逻辑：**
- `md5_password(pwd)`：MD5 加盐加密存储。
- `require_role(*roles)` 装饰器：角色权限匹配拦截器，API 返回 401/403，页面重定向。
- 权限矩阵：管理员（全功能）/ 就业专员（筛选+导出）/ 访客（仅浏览）。
- 全操作日志记录（登录、导入、编辑、导出、归档等）。

## 七、运行与部署

### 7.1 本地单机部署（默认）
```bash
pip install -r requirements.txt
python init_db.py      # 初始化数据库 + 样例数据（仅首次）
python app.py          # 启动，访问 http://127.0.0.1:5000
```

### 7.2 云端 MySQL 部署
```bash
set JOB_DB_TYPE=mysql   # Windows
export JOB_DB_TYPE=mysql  # Linux
# 修改 config.py 中 MYSQL_CONFIG 为实际数据库信息
pip install pymysql
python init_db.py && python app.py
```

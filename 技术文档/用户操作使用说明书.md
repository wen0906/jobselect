# 岗位智能筛选可视化管理系统 V1.0 用户操作使用说明书

## 一、系统概述

**岗位智能筛选可视化管理系统 V1.0** 是面向东西部劳务协作就业服务场景的原创定制软件，支撑杭州、惠州两地海量招聘岗位的标准化入库、多维度智能筛选、数据可视化统计、岗位详情生成与报表导出。

本系统将人工 1 小时的岗位筛选工作缩短至 10 秒，自动生成劳务协作对接报表，精准识别爱心帮扶岗位，助力大龄、低学历、无技能困难群体就业。

## 二、访问与登录

### 2.1 启动系统
1. 确保已安装 Python 3.8+；
2. 在项目根目录执行 `pip install -r requirements.txt` 安装依赖；
3. 首次运行执行 `python init_db.py` 初始化数据库与样例数据；
4. 执行 `python app.py` 启动系统；
5. 浏览器访问 **http://127.0.0.1:5000**。

### 2.2 登录方式

**方式一：账号密码登录**
| 角色 | 账号 | 密码 | 适用场景 |
|------|------|------|----------|
| 管理员 | admin | admin123 | 岗位数据管理、导入、备份 |
| 就业专员 | zhuanyuan | yuan123 | 筛选、可视化、导出报表 |
| 访客 | guest | guest123 | 浏览查询岗位 |

**方式二：快捷演示登录**
登录页底部提供三个角色快捷按钮（管理员/就业专员/访客），点击即可一键进入对应角色，便于演示体验。

## 三、可视化大屏首页

登录后默认进入可视化大屏首页，包含三大区域：

### 3.1 多维度筛选条件条
位于页面顶部，支持以下筛选维度自由组合：
- **地区**：全部 / 杭州 / 惠州
- **行业**：15 个行业类型可选
- **学历（可胜任）**：选择学历后，系统返回该学历可胜任的岗位（岗位要求学历 ≤ 所选学历）
- **最低月薪**：输入金额，返回最高薪资 ≥ 该值的岗位
- **班次**：长白班 / 两班倒 / 三班倒 / 弹性班次
- **福利标签**：20 项标准化福利（五险一金、包吃住、双休、高温补贴等）
- **仅看爱心岗位**：勾选后仅显示爱心帮扶岗位
- **持证优先岗位**：勾选后仅显示需要持证的岗位
- **关键词**：模糊匹配岗位名称或企业名称

点击 **「应用筛选」** 后，下方全部指标卡片与图表自动联动刷新；点击 **「重置」** 清空全部条件。

### 3.2 核心指标卡片（4 张）
- 📊 岗位总数
- ♥ 爱心帮扶岗位数
- 💰 8000 元以上高薪岗数
- 🏠 包食宿岗位数

### 3.3 ECharts 可视化图表
- **柱状图**：各行业岗位数量对比
- **饼图**：学历分布占比
- **饼图**：薪资区间分布占比（4000 以下 / 4000-6000 / 6000-8000 / 8000-10000 / 10000 以上 / 面议）

> **联动机制**：任意筛选条件变更并应用后，所有图表自动重新统计数据并重绘。

## 四、岗位筛选列表页

点击顶部导航 **「岗位筛选」** 进入。

### 4.1 筛选操作
页面顶部提供与可视化大屏一致的复合筛选条件（地区、爱心岗位、学历、薪资、行业、班次、福利、持证、关键词），支持 9 个维度叠加筛选。点击 **「查询」** 后：
- 顶部 4 张指标卡片实时更新匹配结果统计
- 下方卡片列表展示匹配岗位，按"爱心岗优先 → 薪资由高到低"排序

### 4.2 岗位卡片展示
每张卡片展示：岗位名称、地区、企业名称、薪资（8000+ 高亮红色）、招聘人数、学历、行业、班次、彩色福利标签、联系电话、联系人。
- 右上角 **♥ 爱心岗位** 标签：黄色底纹标记爱心帮扶岗位
- 右上角 **持证优先** 标签：紫色底纹标记需持证岗位

### 4.3 导出功能（管理员/就业专员）
- **「导出报表」**：将当前筛选结果导出为标准化劳务对接 Excel 报表（含标题行、表头、数据行，爱心岗黄底高亮）
- **「导出联系人」**：批量导出企业联系人、联系电话，用于线下招工通知

> 访客角色不显示导出按钮，访问导出接口会被权限拦截返回 403。

### 4.4 分页
底部提供分页导航，每页 12 条，支持上/下页与页码跳转。

## 五、岗位详情页

在岗位列表点击任意卡片进入岗位详情页，展示完整岗位信息：
- 头部：地区、爱心岗位/持证优先徽章、岗位名称、企业名称、薪资
- 信息网格：招聘人数、学历、行业、班次、持证要求、岗位状态
- 福利待遇标签（彩色）
- 岗位职责、福利待遇原文
- 联系信息卡片（电话、联系人、企业）

### 5.1 操作按钮
- **🖨 打印本页**：调用浏览器打印，适配 A4 纸张
- **📱 生成独立详情页(转发)**：生成可独立访问的静态 HTML 文件，弹窗显示访问地址，适合微信转发、手机浏览、线下打印招工材料
- **📊 导出该岗位到 Excel**（管理员/就业专员）：将该岗位加入报表导出

## 六、后台数据管理（仅管理员）

点击顶部导航 **「后台管理」** 进入，提供 5 个功能标签页：

### 6.1 岗位数据管理
- 表格列出全部岗位（支持按企业/岗位/地区搜索，分页 15 条/页）
- 每行提供 **编辑 / 上架·下架 / 删除** 操作
- 爱心岗位整行黄色底纹标识
- 点击 **「+ 新增岗位」** 打开编辑弹窗，填写信息后系统自动执行数据清洗（薪资拆分、学历分级、福利标签拆分、爱心/持证识别）

### 6.2 Excel 导入
1. 点击文件选择框上传 `.xlsx` / `.xls` 岗位台账文件
2. 点击 **「上传并解析」**，系统自动执行：文本解析 → 数据清洗 → 标签拆分 → 入库
3. 返回导入结果：成功条数、跳过条数、错误明细
4. 点击 **「下载导入模板」** 获取标准表头 CSV 模板

**Excel 表头要求（首行命名）：**
`企业名称、联系人、联系电话、岗位名称、招聘人数、薪资、学历要求、地区、行业、班次、岗位职责、福利待遇、备注`

### 6.3 归档与备份
- 选择月份，点击 **「生成归档快照」**：将当前全部在岗数据生成 JSON 快照存入归档表
- 归档列表展示历史归档记录，点击 **「恢复」** 可从快照恢复岗位数据（覆盖当前在岗数据）

### 6.4 用户管理
展示系统全部用户列表（账号、角色、创建时间），并附权限说明。

### 6.5 操作日志
展示最近 200 条操作日志（时间、操作人、操作类型、详情），涵盖登录、导入、编辑、删除、导出、归档等全部操作。

## 八、常见问题

**Q1：忘记密码怎么办？**
A：管理员可登录数据库执行 `DELETE FROM user WHERE username='xxx'`，再重新运行 `init_db.py` 重建默认账号；或联系系统管理员重置。

**Q2：Excel 导入失败怎么办？**
A：检查表头是否与要求一致；系统会返回错误明细（行号 + 原因），按提示修正后重新导入。

**Q3：筛选结果为空？**
A：尝试放宽筛选条件，或点击「重置」清空全部条件后重新筛选。

**Q4：生成的详情页如何分享？**
A：在岗位详情页点击「生成独立详情页」，弹窗中的链接可在微信中直接打开转发；生成的 HTML 文件位于 `data/detail_pages/` 目录。

**Q5：如何切换到 MySQL 云端部署？**
A：设置环境变量 `JOB_DB_TYPE=mysql`，修改 `config.py` 中 `MYSQL_CONFIG`，安装 `pymysql` 后重启即可。
